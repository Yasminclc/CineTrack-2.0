sobre o projeto

Um catálogo com
gosto pessoal.

O CineTrack reúne uma seleção pessoal de filmes que já assisti. A proposta é organizar essas escolhas em uma experiência simples, visual e interativa.

As notas são pessoais e não representam crítica profissional ou avaliação técnica.

Reunir uma seleção variada de filmes que já assisti, permitindo que cada pessoa encontre algo diferente para conhecer ou rever.

A nota vai de 1 a 10 e representa somente o quanto eu gostei da experiência com aquele filme. Ela não pretende substituir críticas ou avaliações especializadas.

A página utiliza Fetch API para buscar os dados em arquivos JSON servidos por HTTP. A listagem e os detalhes usam fontes separadas, e a interface é montada dinamicamente com JavaScript.

Sim. O layout usa o sistema de grid do Bootstrap e estilos responsivos próprios para adaptar navegação, filtros, cards, modal e trailer a diferentes tamanhos de tela.
